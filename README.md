# Math Lock-In: MATH20290 Multivariable Calculus for Engineers

Cram notes for the MATH20290 final exam (UCD, 2026–27), built from the lecture notes, problem sheets 1–5, the official solutions and the sample exam.

Start at **[TOPICS.md](TOPICS.md)** (progress tracker).

- Questions I asked: **[questions-asked.md](questions-asked.md)**
- Mock exams: **[Mock 1](mock/midterm-1.md)** · **[Mock 2](mock/midterm-2.md)**
- Practice site (if GitHub Pages is on): `index.html` reads the `questions/` and `mock/` md files directly.

## The exam

- 2 hours. 6 questions. All equal marks.
- No formula sheet. Non-programmable calculator only.
- Leave answers in **exact form** (√2, π, ln 3, e²), simplified.

## Reading style (dyslexia-friendly)

- One idea per line. Short sentences.
- Big equations on their own line.
- Lots of space between sections.

## How each topic is built

- `notes/NN-topic.md`: a snippet of the lecture-notes page, then **"How to read this…"** in plain words, then a **🧠 check** question (answer hidden; try it first).
- **📐 boxes** for every equation or method: what each symbol means, when to use it, when not to.
- **⭐ Learn by heart** list at the top of each topic.
- A **worked example** from a real tutorial or sample-exam question.
- A **method table** at the end: "You're asked for… / Use…".
- `questions/NN-topic.md`: end-of-topic test.
  - Part A: the tutorial questions with full answers.
  - Part B: exam-style questions in other formats (true/false, multiple choice, calculate, sketch, explain).
- Every answer cites the notes section (§) it comes from.

## Answers

- Sheets 1–3 and the sample exam: the official solutions.
- Sheets 4 and 5: the short answers printed on the sheets, with the full working written by me and checked in Python (sympy). Marked "unofficial working".
